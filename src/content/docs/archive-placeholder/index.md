This directory is not a RustFox release and not a docs archive.

`starlight-versions` requires at least one archived slug. The folder exists so the plugin does not copy current docs into a fake version on the first build. **Latest** on the version switcher is the current site (`main`).

A real archive is added after a RustFox GitHub Release tag. Docs may lag that tag. Versioning is not a release gate. See [NOTES.md](https://github.com/chinkan/rustfox-docs/blob/main/NOTES.md).
